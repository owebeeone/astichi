# History Index

Use [the current documentation index](../README.md) for active work.

- Root documents and `v1_issues/`, `v2_issues/`, `v3_issues/` preserve the
  former `dev-docs/historical/` material, including unresolved ideas as well as
  completed designs. Archival placement is not implementation acceptance.
- `composition/` contains the implemented elif, match-case, and fallback-hole
  support proposals. Current behavior is documented in the active summary,
  reference snippets, and goldens.
- `perf-refactor/` contains earlier benchmark snapshots, inventory-first and
  hybrid/native rollout designs, and their slice/ABI/compile/handoff ledgers.
- The existing import-planning documents remain at the root of this archive.

Moved files retain their original contents. Quoted paths and revisions describe
the original checkout; use the pinned revision when reproducing an old result.
The [original historical index](README.md) is retained unchanged as a record,
not a current catalogue.
