# astichi dev-docs

**Internal design notes, proposals, and project history — not user documentation.**

These pages record *why* astichi is built the way it is: design rationale,
performance analyses, feature proposals, and superseded specifications. Content
here may be out of date, describe ideas that were never implemented, or reflect
an earlier design that has since changed.

If you are **using** astichi, go to:

- the documentation site — <https://owebeeone.github.io/astichi/>
- the repository [`README.md`](../README.md)

Everything under `dev-docs/` (including `historical/` and `history/`) is kept for
contributors and future maintainers, not as a reference for building against the
library.
